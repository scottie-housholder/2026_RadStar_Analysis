This repo is a public copy of the analysis done by Taylor University students on NearSpace Launch's RadStar Data. It includes scripts that were used to analyze the data collected by NearSpace Launch in 2025, written by Nathan Jackson and Scottie Housholder with guidance from Dr. Fola Ayano.

The dataset used in this study is not included in this repo, but it is available upon request from NearSpace Launch, Upland, Indiana.

Requirements

The included scripts were written with Python v3.13.13 and utilize these libraries:

- `Astropy`
- `geopandas`
- `matplotlib`
- `NumPy`
- `pandas`
- `matplotlib`
- `scikit-learn`
- `SciPy`
- `Seaborn`
- `shapely`
- `statsmodels`

You can install them all at once using pip:

```sh
pip install geopandas astropy matplotlib NumPy pandas matplotlib scikit-learn SciPy Seaborn shapely statsmodels
```
